ПР2. Ответы на контрольные вопросы

1. Почему для хранения денег используют decimal, а не double? Что может пойти не так с double?

double хранит число в двоичном виде, и некоторые десятичные дроби не могут быть представлены точно - накапливается погрешность

decimal устроен так, что подобных проблем не возникает

2. Что произойдёт, если целочисленный тип (например, byte) переполнится — то есть значение выйдет за границы диапазона?

Если результат выходит за пределы, значение оборачивается по кругу заново от минимума 

3. Чем var отличается от динамической типизации в Python? В какой момент компилятор определяет тип переменной, объявленной через var?

var в C# это неявная типизация который определяет тип переменной при компиляции на основе присвоения значения

В Python используется динамическая типизация где тип может меняться в любой момент выполнения программы

4. Какой тип данных всегда возвращает Console.ReadLine(), независимо от того, что ввёл пользователь?

string

5. Чем int.Parse отличается от int.TryParse в поведении при некорректном ввод (например, буквы вместо цифр)?


int.Parse при некорректном вводе бросит исключение FormatException, произойдет ошибка

int.TryParse вернет false в булеву переменную и запишет 0 в целевую переменную

6. Что означает false, возвращённый из int TryParse, и что при этом попадёт в переменную, переданную через out?

Когда int.TryParse возвращает false это означает что преобразование строки в число не удалось

В переменную переданную через out попадет значение 0

7. Приведите пример, когда стоит использовать TryParse, а не Parse и объясните,почему

При работе когда пользователь может ввести что угодно лучше использовать TryParse он позволит избежать краша программы и обработает ошибку корректно, а Parse просто упадет
